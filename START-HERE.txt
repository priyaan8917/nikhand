RUN THE ENTIRE PROJECT ON WINDOWS

1. Extract the ZIP first. Do not run files from inside the ZIP.
2. Open the nik folder containing package.json, angular.json and RUN-NIKHAND.cmd.
3. Double-click RUN-NIKHAND.cmd.
4. Wait while dependencies install. Internet is required for the first installation.
5. The browser opens when Angular starts. Otherwise open http://localhost:4200/.
6. Keep the command window open. Press Ctrl+C to stop.

MANUAL METHOD IN VS CODE
File > Open Folder > choose this nik folder.
Terminal > New Terminal.
Run each command separately:
  npm.cmd install
  npm.cmd start
Open http://localhost:4200/.

Do not run npm from Desktop. The terminal must show the folder containing package.json.
Do not create a new Angular project; all required source/configuration files are here.
Use Node.js 22 for this Angular 18 project. Check using node --version.
